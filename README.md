# Transpolo | Demonstração web

Demonstração da Central de Operações, com consulta de deslocamentos e rascunhos de lançamento. Todos os locais e valores são fictícios; não utilizar para cobranças ou registros oficiais.

## Acesso
Após ativar o GitHub Pages em Settings > Pages, escolha Deploy from a branch, branch main e /(root). Endereço previsto: https://samuelbarrosmacedo.github.io/transpolo-web/.

Também é possível baixar index.html e abrir no navegador, sem instalação. Selecione A — Base de teste, B — Terminal de teste e CARRO ou VAN. As referências de rascunho são temporárias e desaparecem ao recarregar a página.

## Limites
Este repositório contém exclusivamente a demonstração pública. Não armazena credenciais, arquivos comerciais, imagens internas ou dados de clientes. Não recebe senhas nem acessa serviços de autenticação. A operação oficial e o ambiente interno são mantidos separadamente. Não publicar conteúdo privado neste repositório.
